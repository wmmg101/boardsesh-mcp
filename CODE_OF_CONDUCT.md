# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful and constructive, assume good faith, keep discussions about the
code and the climbing, and don't harass anyone. This applies in issues, pull requests,
discussions and any other project space.

Two project-specific points:

- Never post anyone's credentials, tokens or personal Boardsesh data, including your own.
  Maintainers will edit or delete such content on sight and may ask you to rotate the
  password.
- This is an unofficial community project. Be courteous about Boardsesh and its maintainers;
  they publish an open API and owe us nothing.

Report unacceptable behaviour privately via
https://github.com/wmmg101/boardsesh-mcp/security/advisories/new (the same private channel used
for security reports) or by contacting the maintainer through their GitHub profile. Reports
are handled confidentially. Maintainers may warn, edit or remove content, or ban repeat
offenders from the project spaces.
